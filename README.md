# Inventario Inteligente

Aplicación Flutter de inventario local para registrar productos, existencias y
movimientos de entrada, salida y ajuste. Este README es el índice de la
documentación técnica; los pasos de instalación se ejecutan desde
[`inventario_inteligente/`](./inventario_inteligente/).
